Portfolio interactif

Faites défiler pour découvrir mon univers : un développeur plongé dans son écran, mes projets et l'énergie créative qui m'animent.

Arrivée dans le studio : rencontrez-moi face à face alors que je code sur mon poste.
Le scroll fait pivoter la caméra derrière moi : observez mon clavier et l'écran où s'affiche « JAVA ».
Un dernier scroll zoome sur l'écran pour révéler des raccourcis vers mes projets.
